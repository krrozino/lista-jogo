# LISTA! 0.7.0-beta.1 — mais variedade, sem perder a simplicidade

**Pré-release beta; não é a versão 1.0.**

## Novidades
- 816 desafios de listas (30 novos); 116 questões de Quiz (30 novas); 80 afirmações de Verdadeiro ou Falso (20 novas).
- **Sobrevivência**: três vidas para enfrentar até 20 perguntas.
- **Favoritas**: marque perguntas e jogue uma rodada só com elas.
- Filtro por categoria para personalizar os novos modos.
- Indicador local de sequência de dias jogados.
- Exportação e importação de dados de Quiz com favoritos e histórico de dias.

## Compatibilidade e limitações
- Todos os 786 IDs anteriores preservados. Recordes existentes permanecem no armazenamento local.
- Ranking online continua exclusivo para Sprint/Turbo e contas autenticadas.
- Dados de favoritos e sequência de dias são locais, não sincronizados com outros dispositivos.
- Listas abertas continuam representando seleções curadas de respostas; envie sugestões pelo botão de avaliação.

## Verificação
- `npm test` para catálogo/quiz e HTML incorporado.
- Testes de navegador para Quiz, Sobrevivência, Favoritas, filtros e tela móvel.
